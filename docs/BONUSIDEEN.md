# Bonusideen

Alle Bonusaufgaben sind freiwillig und zählen nicht zur Basiszeit und
nicht zur Bewertung. Die festen Bonus-Prompts im Kurs:

| Prompt | Idee |
| ------ | ---- |
| `L01-B01-farbschema.prompt.md` | Eigenes Farbschema |
| `L02-B01-raster-umschalten.prompt.md` | Gitternetz per Taste ein-/ausblenden |
| `L03-B01-alternative-steuerung.prompt.md` | Zweite Tastenbelegung (WASD) |
| `L04-B01-debug-anzeige.prompt.md` | Debug-Infos per Taste |
| `L05-B01-ghost-piece.prompt.md` | Landeposition als Umriss anzeigen |
| `L06-B01-hold-funktion.prompt.md` | Stein auf Halten legen |
| `L07-B01-eigene-erweiterung.prompt.md` | Freie eigene Erweiterung |

## Weitere Ideen für deine eigene Erweiterung

- Vorschau der nächsten **mehreren** Steine
- Highscore mit Speicherung in einer Datei
- Musik oder Soundeffekte
- Startbildschirm mit Titel
- Animationen beim Reihen-Entfernen
- Schwierigkeitsmodi (schneller Start, andere Level-Schritte)
- Tastatursteuerung anpassbar machen
- Statistik (gefallene Steine, durchschnittliche Punkte)

## Regeln für eigene Erweiterungen

1. Setze zuerst die Basisfunktionen sauber um.
2. Nimm dir genau **eine** Erweiterung vor.
3. Teste nach jedem Schritt — deine Basistests müssen grün bleiben.
4. Dokumentiere die Erweiterung in deiner README.
